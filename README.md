# Python

A sequential collection of small Python projects, numbered in the order they were built (01 → ...), following a 50-project spiral curriculum that gradually increases in scope and complexity.

## How This Repository Is Organized

Each notebook is a self-contained mini-project — starting from simple console programs (ATM simulation, number guessing, calculator) and progressing toward projects with more state and structure (budget tracker). Earlier projects focus on core control flow and functions; later ones introduce more realistic data handling and multi-step logic. The numbering reflects build order, not difficulty tiers.

**Tech stack:** Python (standard library, no external dependencies beyond what a given project needs)

**Format:** Each notebook is self-contained — problem description in comments/markdown, followed by the implementation.
